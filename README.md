# Planar-Free-floating-Space-Manipulator-MuJoCo-Model-
Here we have created a .xml file for creating the Mujoco model of the planar-free floating SMS. Then we have shown forward kinematics, joint-space and cartesian space control.
This project implements a planar free-floating space manipulator (SMS) in MuJoCo. A joint-space PD controller is used to drive the manipulator to a desired configuration while demonstrating the dynamic coupling between the manipulator and the floating base.
